The user's new transparent logo is located at:
https://i.imgur.com/P5SoPEh.png

START-NOVA.bat / BUILD-WINDOWS.bat automatically download it and generate:
  logo.png (the original transparent user logo)
  icon.png (Electron's window/taskbar icon)
  icon.ico (Windows EXE, installer and taskbar)

If Imgur blocks the automatic download:
1. Open the link above in Chrome/Brave.
2. Save the PNG directly to this folder as logo.png.
3. Run the .bat file again. It will convert logo.png automatically.

Do not save the Imgur webpage as an image. Use the actual transparent PNG.
